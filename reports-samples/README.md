# Sanitized Report Samples

These PDF and XLSX files contain fictional demonstration values only. They are generated from the same renderers used by the authorized report export endpoints:

```powershell
corepack pnpm --dir source --filter @bcis/api samples:reports
```

The samples demonstrate layout and file structure. They do not prove live PostgreSQL reconciliation, target-printer behavior, approved branding, or final laboratory report-field requirements.
