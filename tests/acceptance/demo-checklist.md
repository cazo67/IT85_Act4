# Live Demo Checklist

Before demo day, fill in the server/client names, PostgreSQL version, commit/tag, API URL, test accounts, printer, and evidence folder. Never write passwords here.

1. Start PostgreSQL/API and show live/ready status.
2. Sign in, change/lock/unlock a test account, and show role-restricted navigation.
3. Open a seeded subscriber/service and generate one billing cycle.
4. Post exact and partial cash payments; print a receipt; show ledger/SOA.
5. Reverse an eligible payment with a reason and show audit history.
6. Show overdue/aging reconciliation and one controlled suspension/reconnection scenario with separate users.
7. Run a balanced collection batch from snapshot through close; show a shortage remaining blocked.
8. Preview, print, and save matching PDF/XLSX reports.
9. Demonstrate a forbidden direct API request using a lower-privilege account.
10. Create and verify a backup; perform restore only on the approved isolated rehearsal target.
11. Run three clients concurrently and repeat a duplicate billing/payment command safely.
12. Show known limitations instead of simulating GCash, advance credit, exception approval, or live infrastructure evidence.
